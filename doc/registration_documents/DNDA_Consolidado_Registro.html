1. DESCRIPCIÓN DEL PROGRAMA

Resumen Ejecutivo

GYMETRA Backend es el núcleo lógico de una plataforma integral de gestión para centros de acondicionamiento físico. El sistema ha sido desarrollado bajo una arquitectura de microservicios distribuida, utilizando el framework Spring Boot (Java 17) y garantizando la persistencia mediante PostgreSQL.

Arquitectura del Sistema

El soporte lógico se divide en tres microservicios principales desacoplados:

  • Login: Autenticación y sincronización vía AWS Cognito.
  • Membresías: Lógica de planes y pagos (Stripe).
  • QR: Motor de acceso dinámico.

Algoritmos de Lógica Original

Sincronización Cognito (Find-or-Create)

Algoritmo que mantiene la identidad local sincronizada con el JWT de Cognito, permitiendo actualizaciones atómicas de perfil sin duplicidad de registros.

Extensión Dinámica de Vigencia

Algoritmo que calcula la nueva fecha de fin sumando la duración del plan a la fecha de vencimiento previa si aún es vigente, evitando traslapes.

2. MANUAL DE OPERACIÓN TÉCNICA

Flujo de Seguridad

El backend opera como un Resource Server OAuth2. El frontend debe obtener un JWT de Cognito y enviarlo en la cabecera Authorization: Bearer [TOKEN].

Endpoints Principales

  • Auth: /api/auth/users
  • Membership: /api/user-memberships
  • QR Access: /api/qr-access/me
