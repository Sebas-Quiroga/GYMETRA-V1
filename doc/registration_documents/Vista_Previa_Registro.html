1. Descripción Técnica del Programa

GYMETRA Backend es el núcleo lógico de una plataforma integral de gestión para centros de acondicionamiento físico. El sistema ha sido desarrollado bajo una arquitectura de microservicios distribuida, utilizando el framework Spring Boot (Java 17) y garantizando la persistencia mediante PostgreSQL.

  • Arquitectura: Microservicios (Login, Membership, QR).
  • Seguridad: OAuth2 + AWS Cognito.
  • Persistencia: PostgreSQL + JPA.

2. Manual de Operación Técnica

El sistema actúa como un Resource Server. Todas las peticiones deben incluir un token JWT válido obtenido mediante el flujo de autenticación de AWS Cognito.

Endpoints Clave:

GET /api/auth/users/{id}
POST /api/user-memberships
GET /api/qr-access/me

3. Muestra de Lógica Original

Fragmento representativo del algoritmo de sincronización de identidad:

@Transactional
public User syncUser(Jwt jwt) {
    String sub = jwt.getSubject();
    return userRepository.findByCognitoSub(sub)
            .map(user -> updateExistingUser(user, jwt))
            .orElseGet(() -> createNewUser(jwt));
}
