# 01 — Contexto

> **¿Qué es esto?** Por qué existe el sistema GYMETRA: qué problema resuelve, qué
> encompassa, qué no, y qué palabras usa el negocio.

## Por qué el contexto va primero

El contexto es la respuesta a la pregunta más básica de un proyecto: **¿esto está
resolviendo el problema correcto?** Sin contexto escrito, cada desarrollador asume una
versión ligeramente distinta del problema, y el sistema sale con la unión de todas esas
suposiciones.

## Contexto de GYMETRA en breve

- **Qué es:** un sistema distribuido para gestionar membresías de gimnasio.
- **Para quién:** administradores del gimnasio (backoffice) y socios (app móvil/web).
- **Qué problema resuelve:** la gestión de socios, planes, pagos y control de acceso
  en un gimnasio, hoy dispersa entre procesos manuales y herramientas sin integrar.
- **Contexto institucional:** proyecto académico del curso de Sistemas Distribuidos,
  8° semestre, Corporación Universitaria del Huila.
- **Instructor:** Jesús Ariel González Bonilla.
