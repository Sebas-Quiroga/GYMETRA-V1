# 03 — Producto

> **¿Qué construimos y para quién?** La visión de producto, el encuadre del problema y las
> decisiones que definen qué es GYMETRA como producto.

## Por qué una sección de producto

El código dice **cómo** está construido. El producto dice **para qué**. Un sistema puede
estar impecable técnicamente y resolver el problema equivocado: por eso el encuadre del
problema se escribe **antes** que la arquitectura, y se revisa cuando cambia el código.
