# Presentación Ejecutiva - GYMETRA

## Diapositiva 1: Portada
*   **Título**: GYMETRA - Plataforma Integral de Gestión de Gimnasios
*   **Integrantes**: Jhon Jamez Nieto, Johan Sebastian Naranjo, Juan Felipe Narvaez.
*   **Curso**: Sistemas Distribuidos.

## Diapositiva 2: El Problema
*   Dificultad en la gestión manual de membresías.
*   Falta de control de acceso automatizado y seguro.
*   Poca visibilidad de métricas de negocio en tiempo real.

## Diapositiva 3: La Solución
*   Sistema distribuido basado en microservicios.
*   Control de acceso mediante tecnología QR.
*   Gestión automatizada de pagos y suscripciones.

## Diapositiva 4: Arquitectura Técnica
*   Backend: Spring Boot 3 + Microservicios.
*   Frontend: Vue.js 3 + Ionic.
*   Infraestructura: Docker + AWS Cognito + Stripe.
*   Base de Datos: PostgreSQL.

## Diapositiva 5: Funcionalidades Core
*   Autenticación Segura (JWT/Cognito).
*   Pasarela de Pagos (Stripe).
*   Control de Acceso con QR dinámico.
*   Dashboard Administrativo con métricas.

## Diapositiva 6: Seguridad y Calidad
*   Cumplimiento de estándares OWASP.
*   Pruebas unitarias e integración (>60% cobertura).
*   Documentación técnica completa.
